# 捷信消金重组

曾经的行业最大消费金融公司因母公司PPF集团问题业务大幅收缩，成为外资消金退潮的标志性事件。

## 背景

- 捷信集团母公司PPF集团创始人彼得·凯尔纳于2021年在直升机坠毁事故中去世
- PPF集团面临债务压力和管理层动荡
- 捷信消金在华业务长期亏损

## 事件时间线

| 时间 | 事件 |
|------|------|
| 2019 | 捷信消金冲击港股IPO失败 |
| 2021 | PPF集团创始人去世 |
| 2022 | 在华业务大幅收缩，裁员数千人 |
| 2023 | 传多家机构洽购捷信消金牌照 |
| 2024 | 业务基本停滞，牌照价值待定 |

## 行业影响

- 外资消金在中国面临文化、监管、竞争三重挑战
- 线下重资产模式在数字化时代缺乏竞争力
- 捷信牌照（注册资本70亿）具有稀缺价值，可能被收购
