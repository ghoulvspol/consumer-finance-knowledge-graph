# 行业增资潮

2024年[[消费金融公司管理办法]]发布后，行业迎来大规模增资潮。

## 增资背景

[[消费金融公司管理办法]]要求：
- 注册资本≥10亿元（实缴）
- 主要出资人持股≥50%
- 过渡期2年（至2026年3月）

## 增资路径

1. 原股东同比增资（最常见）
2. 引入新股东
3. 股权转让
4. 牌照转让（极端情况）
