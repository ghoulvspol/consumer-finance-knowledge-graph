# 征信断直连实施

2022年7月，征信断直连正式实施，信贷机构不得直接从互联网平台获取用户信用信息。

## 政策背景

- 2021年9月：《征信业务管理办法》发布
- 2022年1月：办法实施
- 2022年7月：过渡期届满，正式执行

## 核心要求

信用信息流转路径从"平台→消金公司"变为"平台→持牌征信机构→消金公司"。

## 行业影响

| 维度 | 影响 |
|------|------|
| 成本 | 数据获取成本上升 |
| 风控 | 可用特征减少，模型需重构 |
| 竞争 | 头部平台数据优势被削弱 |
| 技术 | 催生[[隐私计算]]技术需求 |
| 合规 | 数据合规体系全面重建 |
