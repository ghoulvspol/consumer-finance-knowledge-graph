# 蚂蚁集团IPO暂缓

2020年11月3日，蚂蚁集团A+H股IPO在上市前两天被暂缓，成为中国金融科技监管的分水岭。

## 事件经过

| 时间 | 事件 |
|------|------|
| 2020.10 | 蚂蚁集团A+H股IPO路演，估值约2.1万亿元 |
| 2020.11.03 | 上交所发布公告暂缓IPO，港交所同步暂缓 |
| 2020.12 | 四部门联合约谈蚂蚁集团 |
| 2021.04 | 蚂蚁集团被要求整改 |
| 2023.07 | 蚂蚁集团被罚71.23亿元 |

## 暂缓原因

1. **花呗、借呗实质为信贷业务**，但按科技公司估值上市
2. 联合贷款中蚂蚁出资比例过低（约1%-2%），[[助贷模式]]风险外溢
3. 数据垄断、[[消费者权益保护|消费者权益保护]]不足
4. [[消费金融牌照|金融牌照]]监管套利

## 行业影响

- **直接催生[[蚂蚁消费金融]]成立**（2021.06）
- 开启整个金融科技行业**强监管时代**
- 推动[[断直连]]、[[消费金融公司管理办法]]等政策出台
- 蚂蚁估值从2.1万亿大幅缩水
- 互联网金融行业信心受挫

## 后续整改

| 阶段 | 进展 |
|------|------|
| 2021.06 | 蚂蚁消金获批成立，注册资本80亿 |
| 2021-2022 | 花呗、借呗业务分批转入消金公司 |
| 2023.01 | 蚂蚁消金增资至230亿元 |
| 2023.07 | 蚂蚁集团被罚71.23亿元，整改基本收官 |
