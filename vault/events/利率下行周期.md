# 利率下行周期

2020年至2026年，消费金融行业经历了持续的利率下行周期，深刻改变了行业盈利模式。

## 利率演变

| 时间 | 行业平均利率 | 驱动因素 |
|------|------------|---------|
| 2020年前 | 24%-36% | 两线三区 |
| 2020.08 | ~15.4%上限 | [[利率监管上限\|最高法调整]] |
| 2021 | ~22% | 竞争+监管 |
| 2022 | ~20% | LPR下调 |
| 2023 | ~18% | 竞争加剧 |
| 2024 | 15%-24% | LPR多次下调 |
| 2025 | 继续下行 | 促消费政策 |

## LPR下调记录

- 2024年：1年期LPR从3.45%降至3.10%（-35BP）
- 2024年：5年期LPR从4.20%降至3.60%（-60BP）
- 2025年：继续下调趋势

## 行业影响

| 维度 | 影响 |
|------|------|
| 盈利 | 单笔利润压缩30%-40% |
| 规模 | 必须通过规模效应弥补 |
| 风控 | [[资产质量与不良率\|风控精度]]要求更高 |
| 竞争 | 尾部公司加速出清 |
| 模式 | 从"高收益覆盖高风险"转向"精细化运营" |
