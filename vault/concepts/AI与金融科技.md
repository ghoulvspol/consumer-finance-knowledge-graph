# AI与金融科技

AI和金融科技是消费金融行业2024-2026年最重要的增长驱动力，渗透风控、客服、营销、催收全链条。

## 技术应用矩阵

| 技术 | 应用场景 | 代表公司 |
|------|---------|---------|
| **智能风控** | 实时反欺诈、信用评估、贷中监控 | 蚂蚁、马上、招联 |
| **AI客服** | 智能外呼、IVR、质检 | 马上（[[天镜大模型]]） |
| **智能催收** | AI语音催收、情绪识别、策略推荐 | 多家消金公司 |
| **大模型** | 知识问答、代码生成、文档审核 | 马上、招联、中银 |
| **RPA** | 运营自动化、报表生成 | 兴业、中邮 |
| [[隐私计算\|隐私计算]] | 联合风控、数据合规共享 | 蚂蚁、招联 |

## 天镜大模型

[[马上消费金融]]自研的"天镜"大模型是行业AI应用的标杆：
- **客服覆盖**：AI客服覆盖率超过90%
- **风控辅助**：实时反欺诈决策
- **催收应用**：AI语音催收，识别借款人情绪
- **研发投入**：营收的5%以上投入科技

## 行业科技投入对比

| 消金公司 | 科技投入占比 | 核心能力 |
|----------|------------|---------|
| 蚂蚁消金 | 高（母公司技术溢出） | 全栈技术能力 |
| 马上消金 | ~5% | 自研大模型、AI客服 |
| 招联消金 | ~3% | 风控模型、数据分析 |
| 兴业消金 | ~2% | 线下数字化 |

## 2026年趋势

- AI监管框架讨论中，大模型应用将面临合规要求
- 隐私计算成为数据合作的标准技术
- 智能催收的消保合规压力增大
