# 消费者权益保护

消费者权益保护（简称"消保"）是2020年后消费金融监管的核心主线之一，贯穿准入、经营、退出全流程。

## 制度框架

### 核心文件
- **2023.03**：《银行保险机构消费者权益保护管理办法》实施
- **2021.02**：大学生互联网消费贷款限制通知
- **2025.03**：《关于促进消费金融公司规范健康发展的通知》

### 八大权益
1. **知情权**：贷款利率、费用必须以IRR口径明示
2. **自主选择权**：不得强制搭售保险或会员
3. **公平交易权**：不得设置不公平的合同条款
4. **信息安全权**：个人信息保护，[[断直连|征信断直连]]
5. **依法求偿权**：投诉处理时限和渠道保障
6. **受教育权**：金融知识普及
7. **受尊重权**：催收行为规范
8. **财产安全权**：资金用途管控

## 催收规范

催收是消保投诉的重灾区。2023年后监管重点规范：

| 行为 | 规范要求 |
|------|---------|
| 暴力催收 | 严禁威胁、恐吓、骚扰 |
| 过度催收 | 限制催收频次和时段 |
| 信息泄露 | 不得向无关第三方透露借款人信息 |
| AI催收 | 需明确告知借款人正在与AI通话 |
| 外包管理 | 消金公司对催收外包承担连带责任 |

## 投诉焦点

根据银保监会消费者投诉数据，消金行业投诉集中在：
1. **利率过高**（占比约30%）— 综合成本高于预期
2. **暴力催收**（占比约25%）— 频繁骚扰、威胁
3. **不当营销**（占比约20%）— 诱导借款、过度授信
4. **信息泄露**（占比约15%）— 个人信息被滥用
5. **合同纠纷**（占比约10%）— 提前还款费用、利率争议
