# 中银消费金融

中国银行控股的消费金融公司，首批4家试点公司之一，全国展业。

## 基本信息

| 维度 | 详情 |
|------|------|
| 成立时间 | 2010年6月 |
| 注册地 | 上海市 |
| 注册资本 | 15.14亿元 |
| 主要股东 | 中国银行（42.8%）、百联集团（22.08%）、陆家嘴金融（13.45%） |

## 核心产品

- **中银消费贷**：信用贷款
- **新易贷**：消费分期

## 特色

- 首批试点公司，行业"元老"
- 中国银行品牌背书
- 2023年曾因贷后管理不到位被罚570万元
