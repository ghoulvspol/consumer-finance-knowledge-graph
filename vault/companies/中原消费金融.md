# 中原消费金融

中原银行绝对控股的消费金融公司，河南省首家消金公司。

## 基本信息

| 维度 | 详情 |
|------|------|
| 成立时间 | 2016年12月 |
| 注册地 | 郑州市 |
| 注册资本 | 20亿元 |
| 主要股东 | 中原银行（78.13%）、河南中原高速公路（12%） |

## 核心产品

- **中原消金APP**：自营渠道
- **提钱花**：消费信贷产品

## 特色

- 河南省首家消金公司
- 中原银行绝对控股（78.13%），股权结构稳定
- 注册资本20亿，已达新规要求
