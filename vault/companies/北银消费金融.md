# 北银消费金融

北京银行参股的消费金融公司，首批试点公司之一，但因骗贷案长期低迷。

## 基本信息

| 维度 | 详情 |
|------|------|
| 成立时间 | 2010年3月 |
| 注册地 | 北京市 |
| 注册资本 | 8.5亿元 |
| 主要股东 | 北京银行（35.29%）、西班牙桑坦德消费金融（20%） |

## 问题事件

2016-2017年"拉人头"骗贷案曝光，多名高管被判刑。此后公司长期低迷，品牌声誉受损。

## 增资压力

注册资本8.5亿，不达标。北京银行持股35.29%，不达标。
