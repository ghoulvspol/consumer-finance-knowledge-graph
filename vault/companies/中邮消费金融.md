# 中邮消费金融

邮储银行背景的消费金融公司，依托4万+网点覆盖下沉市场和农村地区。

## 基本信息

| 维度 | 详情 |
|------|------|
| 成立时间 | 2015年11月 |
| 注册地 | 广州市 |
| 注册资本 | 30亿元 |
| 贷款余额 | ~500亿元（2024年估算） |

## 股东结构

| 股东 | 持股比例 | 备注 |
|------|---------|------|
| 邮储银行 | 36.17% | 主要出资人（<50%，不达标） |
| 星展银行 | 15% | 外资银行 |
| 渤海国际信托 | 15% | 信托 |
| 拉卡拉 | 13.33% | 支付 |
| 神州优车 | 12% | 产业 |

## 核心产品

- **邮你贷**：信用贷款
- **邮你花**：消费分期

## 特色

- 依托邮储银行4万+网点，下沉覆盖能力强
- 农村市场优势明显
- 主要出资人持股36.17%，需调整至50%
