# 兴业消费金融

兴业银行控股的消费金融公司，以线下展业为主，客群质量和[[资产质量与不良率|资产质量]]行业领先。

## 基本信息

| 维度 | 详情 |
|------|------|
| 成立时间 | 2014年12月 |
| 注册地 | 福建省泉州市 |
| 注册资本 | 53.2亿元 |
| 法定代表人 | 郑海清 |
| 贷款余额 | ~800亿元（2024年估算） |
| 2023年净利润 | ~22亿元 |

## 股东结构

| 股东 | 持股比例 | 贡献 |
|------|---------|------|
| 兴业银行 | 66% | 资金、风控、渠道 |
| 泉州文旅集团 | 24% | 地方国资 |
| 特步国际 | 10% | 产业资本 |

## 核心产品

- **空手到**：信用贷款产品
- **家庭消费贷**：面向家庭的消费信贷
- **兴才贷**：教育消费贷款

## 特色

- **线下展业为主**：依赖网点和客户经理，客群筛选严格
- **不良率控制优秀**：约2%，行业最低水平之一
- **兴业银行控股**（66%）：资金成本低，风控体系成熟
