# 招联消费金融

行业盈利能力最强的消费金融公司，中国联通与招商银行各持股50%的"黄金搭档"。

## 基本信息

| 维度 | 详情 |
|------|------|
| 成立时间 | 2015年3月 |
| 注册地 | 深圳市前海 |
| 注册资本 | 100亿元 |
| 法定代表人 | 章杨清 |
| 贷款余额 | ~2500亿元（2024年估算） |
| 2023年营收 | ~196亿元 |
| 2023年净利润 | ~36亿元 |
| 员工人数 | ~5000人 |

## 股东结构

| 股东 | 持股比例 | 贡献 |
|------|---------|------|
| 中国联通 | 50% | 通信渠道、用户数据 |
| 招商银行 | 50% | 资金成本、风控体系 |

## 核心产品

- **好期贷**：现金贷产品
- **信用付**：消费分期产品
- **招联金融APP**：自营渠道

## 竞争力

- **利润率行业第一**：2023年净利润率约18%
- **不良率控制优秀**：约2.5%，行业领先
- **累计服务客户**超2亿人次
- **[[消费金融公司监管评级|监管评级]]**较高
