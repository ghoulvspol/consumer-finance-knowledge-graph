# 晋商消费金融

晋商银行参股的消费金融公司，规模较小，面临增资和持股比例双重压力。

## 基本信息

| 维度 | 详情 |
|------|------|
| 成立时间 | 2016年2月 |
| 注册地 | 太原市 |
| 注册资本 | 5亿元 |
| 主要股东 | 晋商银行（40%）、奇飞翔艺（25%）、天津宇信易诚（20%） |

## 增资压力

- 注册资本5亿，不达标（需≥10亿）
- 主要出资人持股40%，不达标（需≥50%）
