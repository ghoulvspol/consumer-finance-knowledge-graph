# 建信消费金融

建设银行控股的消费金融公司，是2023年获批的最后一家消金公司，标志着国有大行亲自入场。

## 基本信息

| 维度 | 详情 |
|------|------|
| 成立时间 | 2023年6月 |
| 注册地 | 北京市 |
| 注册资本 | 72亿元 |
| 主要股东 | 建设银行（83.33%）、王府井集团（11.11%）、北京金阳房地产（5.56%） |

## 行业意义

- **最后一张消金牌照**：此后新设牌照几乎停批
- **国有大行入场**：建行持股83.33%，是银行持股比例最高的消金公司
- **资金成本极低**：依托建行资金优势
- **行业格局震动**：大行亲自下场，对中小消金公司形成竞争压力

## 核心产品

- 建信消费贷（筹备上线中）
