# 蚂蚁消费金融

行业规模最大的消费金融公司，承接[[蚂蚁集团]]旗下花呗、借呗业务，是[[消费金融牌照|消金牌照]]制度下最具标志性的公司。

## 基本信息

| 维度 | 详情 |
|------|------|
| 成立时间 | 2021年6月 |
| 注册地 | 重庆市 |
| 注册资本 | 230亿元（行业最高） |
| 法定代表人 | 黄浩 |
| 贷款余额 | ~1.2万亿元（2024年估算） |
| 员工人数 | ~3000人 |

## 核心产品

- **花呗**：消费分期产品，嵌入支付宝生态
- **借呗/信用贷**：现金贷产品，后更名为"信用贷"
