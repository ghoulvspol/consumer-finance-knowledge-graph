# 捷信消费金融

曾经的行业最大消费金融公司，外商独资，因母公司PPF集团问题业务大幅收缩。

## 基本信息

| 维度 | 详情 |
|------|------|
| 成立时间 | 2010年10月 |
| 注册地 | 天津市 |
| 注册资本 | 70亿元 |
| 主要股东 | 捷信集团PPF（100%） |

## 行业地位变迁

- **2010-2019**：行业最大消金公司，线下模式覆盖全国
- **2019**：冲击港股IPO失败
- **2021**：母公司PPF集团创始人去世
- **2022**：在华业务大幅收缩，裁员数千人
- **2023-2024**：业务基本停滞，牌照价值待定

## 教训

- 外资消金在中国面临文化、监管、竞争三重挑战
- 线下重资产模式在数字化时代缺乏竞争力
- 母公司风险直接传导至中国子公司
