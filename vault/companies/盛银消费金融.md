# 盛银消费金融

盛京银行控股的消费金融公司，注册资本行业最低，面临最大增资压力。

## 基本信息

| 维度 | 详情 |
|------|------|
| 成立时间 | 2016年2月 |
| 注册地 | 沈阳市 |
| 注册资本 | **3亿元**（行业最低） |
| 主要股东 | 盛京银行（60%）、大连德旭（20%） |

## 增资压力

[[消费金融公司管理办法]]要求注册资本≥10亿元，盛银仅3亿，需增资**233%**才能达标。盛京银行自身经营压力大，增资能力存疑。
